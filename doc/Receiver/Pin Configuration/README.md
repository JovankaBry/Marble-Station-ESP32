# Receiver Pin Configuration

We are using `7 servos` , `1 sensors` , `4 DC Motor`
## Servos
- 3 Servos for ball gate
- 4 Servos for ball door

## DC Motors
- 4 DC Motors for ball lift

## Sensor
- 1 Sensor to control 3 Servos for ball gate and 4 motors for the lift

These are the list and the pins for the receiver:

| Component |  GPIO   |
|----------:|---------|
|  Servo 1  |    13   |
|  Servo 2  |    12   |
|  Servo 3  |    14   |
|  Servo 4  |    27   |
|  Servo 5  |    26   |
|  Servo 6  |    25   |
|  Servo 7  |    33   |
|  Motor 1  | 16 & 17 |
|  Motor 2  | 21 & 22 |
|  Motor 3  | 32 & 15 |
|  Motor 4  | 19 & 18 |
|  Sensor 1 |   34    |
